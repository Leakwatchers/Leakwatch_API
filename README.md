# Leakwatch API

**API back-end para monitoramento de vazamentos utilizando IoT**

---

## Sobre o projeto

A Leakwatch API é o back-end do projeto Leakwatch, responsável pelo gerenciamento dos dados dos sensores e pela comunicação com dispositivos IoT através do protocolo MQTT.

O projeto foi desenvolvido utilizando Java e Spring Boot, com integração a banco de dados PostgreSQL e comunicação segura com o broker MQTT.

- Comunicação com dispositivos IoT via MQTT
- Recebimento de dados dos sensores
- Gerenciamento dos dados de monitoramento
- Integração com PostgreSQL
- Comunicação segura com broker MQTT
